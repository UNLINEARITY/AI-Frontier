# GPT Transcribe and GPT Live Transcribe

[Official source](https://developers.openai.com/api/docs/changelog)

Released GPT Transcribe for accurate file transcription and final transcripts of committed Realtime turns, along with GPT Live Transcribe for low-latency streaming transcription. Both models support free-form transcription context, keyword hints, and multiple expected input languages. Compare supported outputs and workflows in the transcription guide.
