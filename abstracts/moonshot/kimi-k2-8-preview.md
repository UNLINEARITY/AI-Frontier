# Kimi K2.8 Preview

## K2.8 Preview (September 11, 2026)

🎉 K2.8 Preview is now fully rolled out in Kimi Code! The Model ID is unchanged — still kimi-for-coding — so clients and third-party tools work with no configuration changes. → Model configuration

Performance close to K3, with more efficient thinking

Coding and agent capabilities are improved across the board, with significantly more efficient thinking than K2.7 Code.

Adjustable thinking effort

Same thinking levels as K3: low / high / max (default max). With thinking turned off, requests to the K3 series and K2.8 Preview are served by K2.8 Preview (no thinking).

1M ultra-long context

A context window of up to 1M is available across all membership tiers.
